## Problem

Presenters often lose flow when they need to jump to a specific slide mid-talk. SlideFlow makes that jump feel natural by letting you search a PDF deck with your voice.

## What I built

- Voice-controlled slide search using the Web Speech API
- Semantic matching with S-BERT and Google Cloud Vision for PDF understanding
- Redis-backed caching to keep repeated lookups fast
- React + Tailwind front end connected to a Flask backend

## Results

- Won **Best Use of AI** at QHacks 2025
- Finished in the **top 4 of 80 teams**

## Why it matters

This project pushed me to connect ML tooling, cloud APIs, and product UX in a tight 36-hour window — and still ship something demo-ready.

## Problem

Build a realistic booking flow with clear separation between front end, API, and database — and prove it with tests.

## What I built

- React front end with component tests via React Testing Library and Jest
- Flask backend with **92% pytest coverage**
- MongoDB persistence and Cypress end-to-end flows

## Results

- Solid SDLC practice across unit, integration, and E2E layers
- A project that demonstrates full-stack ownership, not just UI polish

## Why it matters

Testing discipline is part of how I build — this project is where that habit became visible.
